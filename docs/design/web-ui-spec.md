# Huoqu Web 端 UI 规范（设计稿 v5 · 科技感）

> 适用范围：`web/`（Vue 3 + Element Plus）。
> v1 浅色极简 → v2 深色操作台 → v3 全浅色 → v4 深色只做顶栏 → **v5 顶栏提亮降饱和 + 按钮改低饱和青绿**。
> 所有色值都用脚本核算过 WCAG 对比度，标注了实测比值（见文末「核算依据」）。

---

## 0. 视觉方向（v5，四轮反馈后的定稿方向）

演进过程与原因：

| 版本 | 做法 | 反馈与结论 |
|---|---|---|
| v1 | 浅色极简，亮蓝 `#3370ff` 为主色 | 「蓝色太多，商务感太强」 |
| v2 | 深色操作台 `#0b1220` 整块侧栏 + 深墨主色 + 青色点睛 | 「颜色太深了，对比起来看久了不舒服」 |
| v3 | 全浅色面 + 墨色文字 + 青色指示 | 疲劳解决，但科技感偏弱 |
| v4 | 深色只占 56px 顶栏；侧栏浅色 | 科技感回来了，但顶栏与近黑按钮仍偏重 |
| **v5** | **顶栏提亮降饱和（`#2a6472`）；按钮改低饱和青绿（`#3f6b68`）** | 本次：解决"看久了累" |

**v5 的核心判断（四轮迭代的收敛点）**：久看疲劳有两个独立来源，要分开治：

1. **大面积深色贴大面积浅色** → 减少深色的**接触面积**（v4 已解决：深色只剩顶栏一条）。
2. **色块的饱和度**→ 降低**饱和度**，而不是只降明度。这是 v5 的关键发现：
   - 近黑 `#111c30` 白字 17:1 —— 数值上"最清晰"，但对比过重，眼睛持续调节吃力；
   - 高饱和青绿 `#0f766e`（饱和 77%）—— 明度降下来了，但彩色刺激强，同样累；
   - 定稿 `#3f6b68`（饱和 **26%**、白字 5.98:1）—— 明度与饱和度都在舒适区。

| 手段 | 具体做法 | 为什么有效 |
|---|---|---|
| 深色只做一条 | 顶栏 `#2a6472`（56px）；侧栏 `#f2f6fb` | 深色接触面积最小化 |
| 顶栏降饱和 | `#164e63`（饱和 89%）→ `#2a6472`（饱和 47%） | 低饱和青灰比高饱和深青耐看 |
| 按钮低饱和 | `#111c30`(17:1) / `#0f766e`(饱和77%) → `#3f6b68`(5.98:1，饱和 26%) | 降低对比与彩色刺激 |
| 墨色做层级 | 文字、强调、图标仍用 `#0f172a` | 不靠重色块，靠文字权重建立层级 |
| 青色做指示 | 只出现在激活条、选中态、实时点、数据对比 | 一屏占比 <5%，是"信号"不是"装饰面" |
| 结构线 + 网格 | 1px 冷灰线；32px 极淡网格（内容 3.5%、侧栏 2.8% 透明） | 用线与纹理建立秩序，不用色块 |

**克制原则**：深色只有顶栏一条；实色填充一律低饱和；青色只做指示器。

## 0. 先说清楚：为什么改、改哪一层

现有界面**能用、也不丑**，问题集中在「没有统一的设计层」：颜色、字号、间距、页头、状态表达都是各页各写一套，于是出现下面这些具体缺陷。规范的目标就是把它们一次性收口。

| 走查发现（已用真实浏览器复现） | 现状 | 本规范对应章节 |
|---|---|---|
| 次级文字对比度不达标 | `--qj-muted #9198a1` 在白底仅 **2.91:1**（看板指标说明、列表副标题、客户编号全靠它） | §2 颜色 |
| 表头文字对比度不达标 | Element 默认 `#909399`，仅 **3.08:1** | §2 / §5.4 |
| 移动端筛选胶囊过小 | 时间/状态胶囊高 **31px**，低于 44px 触控标准 | §5.6 |
| 表格操作按钮过小 | 客户表「派单/详情」为 24px 高的 mini 按钮 | §5.6 |
| 指标卡标签折行、卡片不等高 | 「最终出货重量 (kg)」被压成两行，逐卡高度不一 | §5.2 |
| 关键列被挤断行 | 任务表「任务号」`QJ20260913-02366D` 折成两行 | §5.4 |
| 详情页状态徽标溢出 | 任务详情右上角「待取」徽标被顶到栏外、贴边裁切 | §5.3 |
| 危险操作拉满整行 | 「取消任务」「再次取件」占满整行，与「管理操作」的语义不符 | §5.3 |
| 详情页表格没有容器 | 客户详情「取件地址」「取件订单」表格直接裸在灰底上，没有卡片边界和表头底色 | §5.5 |
| 页头样式不统一 | 看板是自定义 `.toolbar` 无副标题，通知中心有副标题，员工/区域页又是另一种 | §5.1 |
| 空状态留白失衡 | 通知中心空状态上下空白比例失调，且没有引导动作 | §5.7 |
| 加载态缺失 | 列表刷新时无骨架屏/`aria-busy`，直接闪空 | §5.7 |

**不改的东西**：品牌主色仍是 `#3370ff`、既有信息架构、路由、任何后端接口与业务逻辑。这是一次纯前端的视觉与交互层升级。

## 1. 设计原则（三条，冲突时按序取舍）

1. **数据优先**：这是派单/对账台，一屏内先看得清「谁、什么时候、什么状态」。装饰让位于可读性 —— 数字用等宽数字、关键列不换行、状态一眼可辨。
2. **克制**：只用一套中性色阶 + 一套语义状态色，不再出现页面自带 hex。层次靠间距和字重，不靠边框和阴影堆叠。
3. **双端同源**：桌面表格与手机卡片是同一份信息的两种排布，不是两套设计。栏目标签、状态文案、颜色语义两端完全一致。

## 2. 颜色令牌

全部落在 `:root`，页面里**禁止再写裸 hex**（`#fff`/`#333` 这类也一样）。

| `--qj-muted` | `#6b7280` | 说明文字、辅助信息（原 `#9198a1` → 2.91:1 ❌） | **4.83:1** ✓ |

| `--qj-accent` | `#0e7490` | **亮底上的青色文字**（白底 5.36:1 / 灰底 4.78:1） |
| `--qj-accent-strong` | `#0891b2` | 青色描边、指示条、开关/复选/滑块激活态 |

> **按钮为什么是低饱和青绿**：实色按钮的疲劳感主要来自**饱和度**，其次才是明度。

> → 定稿 `#3f6b68`：饱和度 26%、白字 5.98:1。数值达标与观感舒适同时满足。

## 3. 字体与字号

**字体族保持不变**（`-apple-system / PingFang SC / Microsoft YaHei` 栈）。理由：部署环境是 NAS 内网、**要求无外部 CDN 依赖**，不能引入 Google Fonts；系统中文黑体在 Windows/macOS/iOS 上都是最优解。数字列统一 `font-variant-numeric: tabular-nums`。

| 令牌 | 字号 / 行高 / 字重 | 用途 |
|---|---|---|
| `--fs-title` | 18px / 1.4 / 600 | 页面标题 |
| `--fs-card` | 15px / 1.4 / 600 | 卡片标题 |
| `--fs-body` | 14px / 1.5 / 400 | 正文、表格、按钮 |
| `--fs-sub` | 13px / 1.5 / 400 | 表头、次要字段 |
| `--fs-meta` | 12px / 1.5 / 400 | 说明、时间戳、副标题 |
| `--fs-badge` | 12px / 1.4 / 500 | 徽标、标签 |
| `--fs-metric` | 28px / 1.2 / 700 | 指标卡数值（原 26px） |

移动端：`--fs-title` → 17px；其余不变（保持 iOS ≥16px 输入框防缩放规则）。

## 4. 间距 / 圆角 / 阴影

**间距**（4px 基准）：`4 / 8 / 12 / 16 / 20 / 24 / 32`，废弃现有的 6/7/9/10/14 等随意值。

| 位置 | 桌面 | 移动 |
|---|---|---|
| 页面内边距 | 20px 24px | 12px |
| 卡片内边距 | 18px 20px | 14px |
| 卡片间距 | 16px | 12px |
| 表单项间距 | 18px | 16px |
| 区块标题下间距 | 14px | 12px |

**圆角**：标签/徽标 6px，按钮/输入 8px，卡片 10px，弹窗/抽屉 12px，胶囊 999px。

**阴影**（收敛为三档，取代各页随手写的阴影）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--shadow-1` | `0 1px 2px rgba(31,35,41,.04)` | 静置卡片 |
| `--shadow-2` | `0 2px 8px rgba(31,35,41,.06)` | 悬停、下拉 |
| `--shadow-3` | `0 8px 24px rgba(31,35,41,.10)` | 弹窗、抽屉 |

## 5. 组件规范

### 5.1 页头（统一为一个组件化结构，替换现在各页各写的 toolbar）

```
[标题 18/600]  [副标题 12/-muted]                    [主操作] [筛选控件组]
────────────────────────────────────────────────────────────────
```

- 标题文案与侧栏菜单项**完全一致**（现在看板叫「经营看板」、菜单叫「数据看板」，统一为「数据看板」）。
- 副标题选填：一句话说明这一页看什么、能做什么（通知中心已有，推广到看板/任务/客户/员工）。
- 主操作（如「新建取件」）固定在右侧，不与筛选控件混排。
- 页头**吸顶**（`position: sticky; top: 0`），滚动时保持可见；下方内容滚动时不被遮挡（`scroll-margin-top`）。

### 5.2 指标卡（看板）

- 布局：图标（40×40，圆角 10px）在左，右侧两行 —— 第一行**标签 13px**，第二行**数值 28px/700 + 单位 13px**，第三行说明 12px。
- **标签不换行**：`white-space: nowrap` + 溢出省略；单位（kg）与数值同行，不再单独占一行。
- 卡片等高：`align-items: stretch`，网格 `repeat(auto-fit, minmax(196px, 1fr))`（现在 1440px 下固定 6 列导致每卡仅约 180px 而折行）。
- 数值为 0 时弱化为 `--qj-muted`，非 0 为 `--qj-text`；有同比时在其后加 `↑/↓ + 百分比`（`--fs-meta`，语义色）。

### 5.3 详情页（任务详情 / 客户详情）

- 顶部返回 + 标题 + **状态徽标放在标题行内**（现在徽标被顶到卡片外边、贴边裁切）。
- 信息分组：客户 / 地址 / 时间 / 联系人为一组，用「标签 88px + 值自适应」的两列网格（移动端单列）。
- **危险操作不拉满整行**：操作区改为 `flex-wrap` + 按钮自然宽度 + 右对齐；「取消任务/停用」用 `plain + danger`，不填满；主操作（再次取件）保持实色但宽度自适应。
- 空的分组**直接不渲染**，不显示空白卡片。

### 5.4 表格

- 容器：表格必须包在卡片内（`border` + `--shadow-1` + 圆角 10px），表头底色 `#fafbfc`、文字 `--qj-text-2` 13px/600（解决 3.08:1）。
- 行高：桌面 44px，移动端卡片 56px 起。
- **关键列禁止折行**：任务号、订单号、面单号、电话、时间戳统一 `white-space: nowrap` + `min-width` 足够宽 + `show-overflow-tooltip`。列宽不足时优先压缩「地址」这类长文本列。
- 状态列用统一徽标（§2.3），不再一半是 `el-tag` 一半是纯文字。
- 行状态着色保留现有「待办/已完成/已取消」淡色底，但改为令牌（`--row-open-bg` 等），不再写死 `#fffdf3`。
- 手机端：一律走现有 `.mobile-list` 卡片形态，卡片左侧 3px 状态色条保留。

### 5.5 卡片与分组

- 三种卡片语义固定：**内容卡**（白底/描边/`--shadow-1`）、**指标卡**（§5.2）、**表格卡**（§5.4）。
- 卡片标题栏统一：图标 + 15px/600 标题，右侧可放次要动作；标题栏底部分隔线用 `--qj-border`。
- 卡片间距统一 16px（移动 12px），不再出现 12/14/16 混用。

### 5.6 触控与交互

- 桌面可点控件最小 **32×32**；移动端主要动作 **≥44×44**。
- 移动端时间/状态胶囊：高度从 31px 提到 **40px**，内边距 8px 16px，间距 8px，**允许换行**（`flex-wrap`，符合 chip 不得裁切的规则）。
- 表格内小按钮：`size="small"` 且加 `.el-button` 最小 32px 高，移动端卡片内按钮 44px。
- 所有可点元素 `cursor: pointer`，悬停态统一 `150ms`（`--dur-fast`），不做布局位移。
- 键盘焦点：全局 `:focus-visible` 可见焦点环 `0 0 0 3px rgba(51,112,255,.35)`，且吸顶栏不得遮挡焦点。
- 尊重 `prefers-reduced-motion`：关闭位移/淡入过渡。

### 5.7 反馈状态

- **加载**：列表/看板首次加载显示骨架块（3–6 行），并加 `aria-busy="true"`；≥300ms 才出现，避免闪烁。刷新时保留旧数据 + 顶部细进度条，不清空内容。
- **空状态**：统一结构 —— 图标（线性 SVG，不用 emoji 当图标）+ 一句说明 + **一个可执行动作**（如「新建取件」「新建客户」）。上下留白对称（32px）。
- **错误**：就地显示（卡片内错误条 + 重试按钮），不只靠顶部 `ElMessage`。

### 5.8 导航

- 侧栏为**浅色操作台**：底 `--qj-chrome #f2f6fb` + 32px 网格纹理 + 右侧 1px `--qj-chrome-border` 结构线。
- 顶栏为**深色细条**：底 `--qj-bar #1b2739` + 渐变，下边线 `--qj-bar-border`。深色只占这一条。
- 品牌区：32px 青色渐变方块（`--qj-accent-bright → --qj-accent-strong → #155e75`）+ 墨色品牌名 + 下方结构线。这是点睛色唯一允许大面积出现的位置。
- 菜单项：42px 高、圆角 8px、文字 `--qj-chrome-text`（6.73:1）、图标 `--qj-chrome-text-dim`；悬停底 `--qj-chrome-hover` + 图标转青；**激活项淡青底 `#d9f2f7` + 深青文字 `#0b4f5c`（7.87:1）+ 左侧 3px 青色指示条**。
- 顶栏右侧：图标按钮描边式（透明底 + `--qj-bar-border`），悬停转亮青 + 10% 亮青底；实时延迟用亮青点 + 呼吸光晕，文字 `--qj-bar-accent-2`。
- 头像：白底 + 深青字（顶栏内唯一高亮块）。
- 移动端抽屉沿用浅色面与菜单样式（菜单项 48px）；顶栏保持深色。
